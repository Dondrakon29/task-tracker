# Task Tracker

A simple Python console project for managing tasks.

## Features

- Add new tasks
- Show all tasks
- Mark tasks as done
- Delete tasks
- Show task status with `[ ]` and `[x]`
- Interactive console menu
- Basic input validation with try / except
- Save tasks to JSON file
- Load tasks from JSON file
- Clear all tasks

## Technologies

- Python
- Git
- GitHub

## How to run

1. Open the project folder
2. Run the file:

```bash
python task_tracker.py
```

3. Choose an option from the menu:

```text
1 - Add task
2 - Show tasks
3 - Mark task as done
4 - Delete task
0 - Exit
```
